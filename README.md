# prognoza-sprzedazy-lodow
Zaawansowana aplikacja do prognozowania tygodniowej sprzedaży lodów oparta na modelach Machine Learning (XGBoost + Prophet), danych pogodowych (Open-Meteo API) i inteligentnie wybranych cechach kalendarza.  Aplikacja działa w przeglądarce dzięki Streamlit — bez konieczności instalowania czegokolwiek poza Pythonem.
